### 🏎️ F1 Qualifying Simulator
[![Repo](https://img.shields.io/badge/GitHub-Repo-181717?style=flat-square&logo=github)](https://github.com/stuart-n-wilson/F1-Qualifying-Monte-Carlo-Simulator)
[![Live App](https://img.shields.io/badge/Streamlit-Live_App-FF4B4B?style=flat-square&logo=streamlit)](https://f1-qualifying-monte-carlo-simulator.streamlit.app/)

`Python` `Streamlit` `Monte Carlo` `LLM Integration`

Monte Carlo simulation engine producing a full driver position probability matrix and probabilistically optimised qualifying results, deployed as an interactive Streamlit application.

- Generates probability distributions for every driver and grid position
- Automatically produces the most likely finishing order with driver and position breakdowns
- Integrated LLM chat interface for interpreting and interrogating results
- Owned end-to-end: simulation architecture, deployment, and LLM integration
